# Визуализатор зависимостей Python — вариант 17

Программа читает метаданные пакетов из JSON API PyPI напрямую через HTTP,
строит граф рекурсивным DFS и выводит описание на языке D2 или ASCII-дерево.
Менеджер пакетов и сторонние библиотеки для получения зависимостей не нужны.
В тестовом режиме используется локальный граф из JSON.

## Требования и запуск

Нужен Python 3.9 или новее. Сборка и установка зависимостей не требуются.
Из корня репозитория:

```sh
sh run.sh A --repository examples/graph.json --test --ascii
sh run.sh A --repository examples/graph.json --test
sh run.sh A --repository examples/graph.json --test --reverse D
sh run.sh requests --repository https://pypi.org --direct
python3 -m unittest discover -s tests -v
```

Параметры: позиционный аргумент — имя пакета; `--repository` — базовый
URL PyPI-совместимого JSON API или путь к JSON-файлу; `--test` включает
локальный граф; `--ascii` выводит дерево вместо D2; `--image` рендерит SVG и открывает его
в браузере через установленную программу D2; `--direct` выводит
только прямые зависимости; `--reverse ИМЯ` выводит все прямые и транзитивные
обратные зависимости в графе, достижимом из исходного пакета. Неизвестный
пакет, неверный адрес, недоступный файл и ошибки сети сообщаются в stderr.

Тестовый JSON — объект, сопоставляющий имена из заглавных латинских букв
спискам зависимостей. Каждая упомянутая вершина должна иметь собственную
запись. В примере есть цикл A → B → D → A, общая зависимость D и отдельная
вершина E. Повторные вершины в дереве помечаются `(already shown)`.

```sh
sh run.sh B --repository examples/graph.json --test --ascii
sh run.sh C --repository examples/graph.json --test --ascii
sh run.sh E --repository examples/graph.json --test --ascii
```

Для получения изображения установите отдельно [D2](https://d2lang.com/), затем:

```sh
sh run.sh A --repository examples/graph.json --test > graph.d2
d2 graph.d2 graph.svg
```

Откройте `graph.svg` в браузере. Файлы визуализации генерируются локально.

## Интерпретация и ограничения

PyPI API сообщает `requires_dist` последней версии. Программа включает все
имена из метаданных, в том числе зависимости с маркерами платформы и extras;
ограничения версий и маркеры не вычисляются. Поэтому граф потенциальных
зависимостей может отличаться от результата `pip install` / `pip inspect`,
которые учитывают среду, выбранные extras и совместимые версии. Для сравнения
можно установить пакет в отдельное виртуальное окружение и изучить вывод
`python -m pip inspect`; это сравнение не является частью работы программы.
Обратные зависимости ограничены построенным графом, а не всем PyPI.
Большие реальные графы требуют много запросов и могут превысить лимит
рекурсии Python. Ошибка загрузки прерывает построение, не скрывая отсутствие
метаданных.
